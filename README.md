# 💼 Jitesh Jain — Developer Portfolio

A **modern, responsive portfolio website** built with **React**, **Vite**, and **Tailwind CSS** — showcasing full-stack projects, AI-powered applications, and an in-depth look at how each one is architected.

### 🚀 [Live Demo](https://jitesh-jain-portfolio.vercel.app/) &nbsp;·&nbsp; 📂 [GitHub Repo](https://github.com/JiteshJain123/Portfolio)

---

## 🛠️ Tech Stack

- ⚛️ **React 19** + **Vite**
- 🎨 **Tailwind CSS**
- 🌀 **GSAP** & **Locomotive Scroll** (animations + smooth scrolling)
- 📦 **Lucide** & **React Icons**
- ✉️ **EmailJS** (contact form)

---

## ✨ Features

- **Case-study project modals** — every project opens a detailed breakdown: the problem, architecture diagram, key metrics, the hardest bug, and what I'd do differently.
- **Command palette** — `Ctrl` / `Cmd + K` for fuzzy search and quick keyboard navigation across the site.
- **Dynamic project filtering** — filter projects by category (All, AI, React).
- **Aurora UI** — animated gradient background, scroll progress bar, and scroll-spy navigation that highlights the active section.
- **Inline resume viewer** — view the PDF résumé in a modal without leaving the page.
- **Blog / Writing** section for technical posts.
- **Fully responsive** across desktop, tablet, and mobile.

---

## 🖼️ Sections

- **Home** — hero with a rotating role headline and quick stats.
- **About** — professional summary, education, and current focus.
- **Skills** — technical toolkit grouped into Languages, Frontend, Backend, AI / GenAI, Databases, and DevOps & Cloud.
- **Projects** — featured full-stack & AI builds, each with a full case study:
  - **ContextOS AI** — AI project-management workspace with a context-aware Gemini assistant and a RAG pipeline over project memory.
  - **SmartIO (SpendWise)** — AI-powered personal finance tracker with an event-driven Celery + Redis backend, a Gemini advisor, and AWS ECS Fargate deployment via GitHub Actions & Terraform.
  - **ViewVault** — full-stack movie-discovery platform with a Node.js/Express TMDB gateway, Redis caching, and a Gemini-powered AI Picks page.
- **Experience** — professional internship plus leadership & community roles.
- **Achievements** — national-level competition milestones.
- **Contact** — get in touch directly from the site.

## 🧑‍💻 Getting Started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build
```

The dev server runs at `http://localhost:5173/`.
